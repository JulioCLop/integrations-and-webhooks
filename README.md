# Integration Hub

A clean UI to connect services, view webhook events, and debug failures.

## Features

- **Services Management**: Connect and manage API integrations
- **Webhooks Viewer**: Real-time webhook event monitoring
- **Debug & Failures**: Track and debug integration failures

## Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- React Router
- Lucide React (Icons)
